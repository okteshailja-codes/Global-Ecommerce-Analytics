#  Global E-Commerce Sales Performance Dashboard

An interactive Power BI dashboard designed to analyze global e-commerce sales performance and identify key business insights.

##  Project Objective

The objective of this project is to analyze global e-commerce data and understand business performance across customer segments, regions, payment methods, and seasons.

##  Key KPIs

- **Total Orders:** 10K
- **Total Revenue:** 5.28M
- **Total Profit:** 1.44M
- **Profit Margin:** 27.21%

##  Dashboard Analysis

- Orders by Customer Segment
- Revenue by Region
- Payment Method Analysis
- Seasonal Performance
- Interactive filtering for deeper analysis

## Tools & Technologies

- **Power BI**
- **DAX**
- **Data Analysis**
- **Data Visualization**

## Key Insights

- Regular customers contribute the largest share of total orders.
- The Middle East and Asia generate the highest regional revenue.
- Interactive filters allow users to explore performance across payment methods and seasons.
